# Agentic workflow image-generation prompts

Generated with the built-in image_gen tool on 2026-10-05. Each PNG is the unchanged RGBA output; transparent_background was true for every call. The architecture catalog was inspected as a visual style reference. No image post-processing, resampling, alpha replacement, or API/CLI fallback was used.

Each atlas is 1774 × 887 pixels and contains eight row-major objects. The original request preferred a larger 2:1 image, and the tool returned this production resolution. The canonical source `../.isostate-assets.yaml` and distributed `../manifest.json` record individually checked whole-pixel crop rectangles and normalized ground-contact anchors. Use the exact rectangles rather than inferring equal rows: the human escalation silhouette rises above the midpoint. Provider objects are visual metaphors, not official product logos. Captions belong in scene text.

Validation: all five files are RGBA with substantial alpha-zero background, and each is below 2 MiB. All 40 silhouettes and their crop boundaries were visually inspected. Anchors were visually measured at the center of the lower contact footprint, then normalized to the recorded rectangle; faint generated contact shadows are preserved.
